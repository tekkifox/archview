# ArchView API Docs

Swagger UI is available at `/docs` once ArchView is running.

The OpenAPI spec is served from `/docs/openapi.yaml`.

Key endpoints:
- `GET /healthz`
- `GET /api/overview`
- `GET /api/architecture`
- `GET /api/architecture?project=image-mosaic`
- `GET /api/docker`
- `GET /api/system`
